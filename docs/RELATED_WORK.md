# Related work

These projects inspired ingestion, transparency and feature hypotheses. Their performance claims have not been independently replicated here.

| Project | Relevant idea |
|---|---|
| [Austin congressional-disclosures](https://github.com/austin-starks/congressional-disclosures) | Extraction, amendment versions, availability semantics and unresolved identity handling |
| [Kadoa congress-trading-monitor](https://github.com/kadoa-org/congress-trading-monitor) | Searchable disclosure presentation and auxiliary provenance |
| [congress-trading-investigation](https://github.com/LosingLoonies-Youtube/congress-trading-investigation) | Open backtest notebooks and comparisons involving disclosures, lobbying and contracts |
| [congress-legislators](https://github.com/unitedstates/congress-legislators) | Stable member identifiers and dated reference data |

[Stanford's TF-IDF reference](https://nlp.stanford.edu/IR-book/html/htmledition/tf-idf-weighting-1.html) explains the information-retrieval intuition. This project's smoothed log-frequency formula is an adaptation for behavioral ranking.

Useful future comparisons include personal novelty versus repeated buying, conditional rarity within similar investors, independent consensus versus correlated advisors, and historical committee relevance. These are hypotheses, not established explanations for returns. Congress Signal Lab does not claim to be the first congressional tracker or the first policy-alignment score.
